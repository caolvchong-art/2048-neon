## 基础规则

和经典 2048 完全一致：方向键滑动，相同数字合并，目标凑出 **2048**。

## 创新玩法

### ⚡ 能量与技能

每次合并都会积攒能量（数字越大给得越多，连续合并不中断还有额外加成），能量可以换技能：

| 技能 | 消耗 | 效果 |
| --- | --- | --- |
| ⚡ 强化 | 30 | 点一个方块让它升一级（数值翻倍） |
| 💣 爆破 | 45 | 点一个方块直接移除，**冰封块也能拆** |
| 🔀 重排 | 35 | 打乱场上所有方块的位置 |
| ⏪ 回溯 | 15 | 退回上一步，最多可回溯 15 步 |

合并 `v` 得到的能量为 `max(1, log2(v) - 1)`。

### 🔥 连击倍率

一次滑动里合并 **2 次以上** 就触发连击，得分按合并次数乘算（最高 **×4**）。
连续多步都有合并会累积「连击链」，链条越长能量收入越高（每级 +10%，最多 +80%）。

### ✦ 万能块

金色的星形方块，可以和**任何**数字合并，吃掉对方后数值翻倍，用完即变回普通块。
第 8 步之后开始有 10% 概率随机出现。

两个万能块合并得到 4。

### ❄ 冰封块

冻住的方块**不能移动、也不能被合并**，会像一堵墙一样把整行/整列切断，彻底改变空间策略。

- 它**周围发生 3 次合并**就会解冻，恢复成原来的数字；
- 或者花 45 能量用爆破直接拆掉。

### 🌀 随机事件

每 **20 步**触发一次，好坏事都有可能：

| 事件 | 效果 |
| --- | --- |
| 🌧 甘霖 | 随机两块方块升级 |
| ❄ 寒潮 | 随机一块方块被冰封 |
| ⚡ 丰收 | 立刻 +40 能量 |
| 🌀 混沌 | 全场位置重排 |
| ☄ 陨石 | 随机摧毁一块方块 |

### 🔮 AI 提示

内置 expectimax 搜索 + 启发式评估（空格数 / 单调性 / 平滑度 / 最大块是否在角上），
免费告诉你它认为当前最好的一步。

## ⌨️ 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | `↑ ↓ ← →` 或 `W A S D` | 在棋盘上滑动 |
| 撤销 | `Z` | 点「回溯」按钮 |
| 重开 | `R` | 点「新游戏」 |
| 提示 | `H` | 点「提示」 |
| 强化 / 爆破 / 重排 | `1` / `2` / `3` | 点技能按钮 |

其他：`Esc` 取消技能指向或关闭弹窗。

还有 4×4 / 5×5 棋盘切换、音效开关、亮暗主题切换，最高分按棋盘尺寸分别保存在 `localStorage`。

## 🚀 本地运行

不需要任何依赖，直接双击 `index.html` 即可。

想用本地服务器（可选）：

```bash
npx serve .
# 或
python -m http.server 8080
```

## 🧪 测试

```bash
npm test
```

- `tests/logic.test.js` —— 用极简 DOM stub 把游戏脚本加载进 Node，跑**真实游戏逻辑**：
  合并/连击、万能块、冰封墙与解冻、无效移动不计分、四个技能、随机事件、
  以及 4×4 与 5×5 各 800 步随机对局（随机混入技能和事件）的棋盘不变量校验。
- `tests/static.test.js` —— 静态检查：JS 引用的 DOM id 是否都存在、CSS 括号与自定义属性是否闭合。

生成用于截图预览的预置棋局页面：

```bash
node tests/make-preview.js
```

## 📦 部署到 GitHub Pages

本项目是纯静态单页，**不需要任何构建步骤**。

### 上手前先自检

```powershell
.\check-env.ps1
```

一次性检查 git / gh / 凭据 / hosts 屏蔽 / 网络可达性，并告诉你还差什么、按什么顺序解决。
（如果你在 DSH 沙箱里跑，网络那两项会显示受限，那是沙箱行为，请在你自己的终端里再跑一次。）

### 方式一：一键脚本（推荐）

```powershell
# Windows
.\deploy.ps1
```

```bash
# macOS / Linux
./deploy.sh
```

脚本会：`git init` → 提交 → 用 `gh` 创建远程仓库 → 推送 → 开启 Pages。

### 方式二：手动

```bash
git init -b main
git add .
git commit -m "feat: 2048 霓虹进化"
git remote add origin https://github.com/<你的用户名>/2048-neon.git
git push -u origin main
```

推送后在仓库 **Settings → Pages** 里把 Source 设为 **Deploy from a branch**，
分支选 `main`、目录选 `/ (root)`，保存后等一分钟即可访问：

```
https://<你的用户名>.github.io/2048-neon/
```

> ⚠️ GitHub Pages 在**私有仓库**上需要付费计划，免费账号请把仓库设为 Public。
